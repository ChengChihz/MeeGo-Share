# Changelog

## 1.005 — 2026-11-06

- Add native “Open now” after receiving a supported single file
- Make the received-files browser open files on tap, without selection controls
- Raise incoming limits to 200 MiB per file and 400 MiB per request
- Check available storage and improve cleanup and recovery after interrupted transfers
- Update all five interface languages

## 1.004 — 2026-11-06

- First public release as MeeShare, with independent branding and a light blue interface
- LocalSend-compatible file transfers, device discovery, multiple selection and configurable receiving
- Simplified Chinese, Traditional Chinese, English, Japanese and Korean interfaces
